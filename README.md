# insurance-calculator

This project is a single-page insurance calculator built with HTML, CSS, and JavaScript. Users enter:

- Age
- Engine power in kW
- Years of driving experience
- New car price
- Coverage type

The calculator immediately estimates an annual premium based on the entered values.

## Run locally

From the project root, start a static server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in the browser.

## Design notes

The application follows the provided design guidelines:

- orange highlight color
- white background
- black text
- dark red for missing input states
- no rounded corners
- sans-serif typography

# insurance-calculator

HTLM5 calculator for a car insurance. User enter:

* Age
* kw of the car
* Number of years of driving experience
* Price of the new car
* Coverage ( only third party, third party + fire and theft, fully comprehensive)

Calculator will immediately return the price of the insurance based on the data entered by user.

## Tech stack

The project is built using HTML5, CSS3, and JavaScript. Single-page HTML5 application with no backend.
